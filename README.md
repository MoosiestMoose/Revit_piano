# Revit_piano
A playable piano in Revit 25 using  Dynamo. 

Instructions :

1 - Download the Revit file - It's Revit 2025

2 - Download wav folder and save on local machine.

3 - Open the, "play selected note" node and update the folder location (just type between the " " ) 

4 - Put Dynamo on periodic mode.

5 - Play
